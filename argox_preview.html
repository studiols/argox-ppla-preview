Pré-visualização

Defina abaixo o tamanho físico total da etiqueta (largura × altura). A prévia se ajusta automaticamente.

Clique em um elemento da etiqueta para ver os dados interpretados.
Prévia visual sem serrilhados ou linhas divisórias, calibrada para o modelo de duas etiquetas da foto. Coordenadas horizontais crescem para a direita; verticais são desenhadas de baixo para cima. O código de barras é ilustrativo, não validado para leitura. Fontes e proporções podem variar no equipamento real.

Como ler os objetos de texto

142000500300025[Preco1]

Na interpretação experimental deste simulador: 1 = rotação; 4 = fonte; 2 e 0 = multiplicadores; 005 = parâmetro adicional; 0030 = posição vertical; 0025 = posição horizontal; [Preco1] = conteúdo.

142000500300220[Preco1] altera a posição horizontal para 0220, criando a segunda coluna. A ordem e a semântica dos campos precisam ser conferidas com o manual da variante PPLA.

Atenção: esta divisão é a adotada pelo parser da prévia, não uma especificação certificada da Argox.

O que o simulador interpreta hoje
Renderiza objetos que correspondem ao padrão reconhecido de 15 caracteres de parâmetros, seguido do conteúdo; substitui variáveis entre colchetes; usa coordenadas e fontes aproximadas; oferece largura, altura e zoom. Não executa todos os comandos de configuração, não garante fontes internas idênticas e não produz códigos de barras validados para leitura.
